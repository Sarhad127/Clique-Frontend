Clique React Frontend

React frontend for the Clique chat application. Connects to a Spring Boot backend and supports real-time messaging via WebSockets.

Features

- User login and registration
- Real-time one-on-one and group chats
- Friend management
- Customizable profiles
- Custom chat backgrounds
- Responsive multi-panel layout

Tech Stack

- React 18
- React Router
- Vite
- WebSockets
- Fetch API
- CSS Modules
